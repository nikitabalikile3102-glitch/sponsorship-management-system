# Sponsorship Management System (Node.js + Express + MySQL)

1. Create the database: run the CREATE TABLE / INSERT script from your report in MySQL Workbench.
2. In this folder:  `npm install`
3. Copy `.env.example` to `.env` and put your MySQL password in it.
4. `npm start`  →  open http://localhost:3000

All data on the site is read from and written to MySQL through `/api/...` (see server.js).
